# creo-plugin-extract-package

An AI agent skill for extracting selected features from an existing PTC Creo TOOLKIT plugin and packaging a standalone plugin with resources, runtime dependencies and DAT registration files.

用于从已有 Creo TOOLKIT 插件中提取指定功能，打包独立插件并验证注册和命令入口。

Read [SKILL.md](SKILL.md) for the workflow, requirements and scope. Supporting references, scripts and assets are included where applicable.
